# License texts

- `GPL-2.0-or-later.txt`: GNU General Public License version 2; the
  “or any later version” option comes from the covered source headers.
- `LGPL-2.1-or-later.txt`: canonical GNU Lesser General Public License
  version 2.1 text. The “or any later version” option comes from the covered
  source notices, including `cpp/core/movie/ffmpeg/RenderFlags.cpp` and the
  selected FFmpeg build.
- `OFL-1.1.txt`: the verbatim Source Han Sans 2.004 notice and SIL Open Font
  License 1.1 text applicable to the bundled Noto Sans CJK 2.004 collection.
  It includes Adobe's copyright and Reserved Font Name notice.
The inherited composite notices and license texts remain in the root
`LICENSE`. Dependency license files generated by vcpkg are installed alongside
each dependency. Use `scripts/collect-third-party-licenses.py` to create the
release artifact; it fails when a resolved package with distributable payload
has no installed copyright file.

The direct UnRAR dependency and the restricted 7-Zip RAR decoder sources are
not part of the build. RAR extraction is provided by libarchive.
